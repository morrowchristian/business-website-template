# Business Website Template

A professionally structured, component‑driven website template built with **Astro** and **Tailwind CSS**.  
This project is designed as a reusable foundation for small business sites, portfolio projects, and agency‑grade client work.

The template emphasizes clarity, modularity, and long‑term maintainability.

---

## 🚀 Features

- Fast, static‑first architecture using Astro  
- Fully responsive layout  
- Reusable UI components (Button, Card, Hero, Header, Footer)  
- Clean folder structure and documentation  
- Centralized data model for navigation and site metadata  
- Tailwind CSS utility‑first styling  
- Easy to extend with new pages, sections, and components  

---

## 📁 Project Structure

'''
src/
├── components/        # Reusable UI components
├── layouts/           # Shared page layouts
├── pages/             # Route-based pages
├── data/              # Global navigation and site metadata
├── styles/            # Global styles and Tailwind config
└── assets/            # Images, icons, and static assets

docs/
├── architecture.md    # High-level project architecture
├── components.md      # Component documentation
├── pages.md           # Page templates and routing
└── decisions.md       # Architectural decision records (ADR)
'''

---

## 🛠️ Tech Stack

- **Astro** — static‑first framework  
- **Tailwind CSS** — utility‑first styling  
- **TypeScript** (optional)  
- **Markdown/MDX** (future support)

## 📦 Getting Started

### 1. Install dependencies

'''
npm install
'''

### 2. Start the development server

'''
npm run dev
'''

### 3. Build for production

'''
npm run build
'''
