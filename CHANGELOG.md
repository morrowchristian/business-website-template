## Versioning Strategy
This project uses **semantic versioning**:

- **MAJOR** — breaking changes  
- **MINOR** — new features  
- **PATCH** — fixes and small improvements  

Roadmap alignment:

- `0.1.x` — Foundation  
- `0.2.x` — Components & Pages  
- `0.3.x` — Styling & Animations  
- `0.4.x` — Enhancements & Polish

## How to Update This File
Each pull request should include an entry under:

- **Added**
- **Changed**
- **Fixed**
- **Removed**

inside the **[Unreleased]** section.  
When a new version is released, move those entries into a new version block.
